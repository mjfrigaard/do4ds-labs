## Penguin Size and Mass by Sex and Species

```{r}
library(palmerpenguins)
library(dplyr)
library(ggplot2)

df <- palmerpenguins::penguins
```

```{r}
df %>%
  group_by(species, sex) %>%
  summarise(
    across(
      where(is.numeric), 
      \(x) mean(x, na.rm = TRUE)
      )
    ) %>%
  knitr::kable()
```

## Penguin Size vs Mass by Species

```{r}
df %>%
  ggplot(aes(x = bill_length_mm, y = body_mass_g, color = species)) +
  geom_point() + 
  geom_smooth(method = "lm")
```

I’ve also included the code from the eda-basic.qmd file in the sections below.

Load data

The code below loads palmerpenguins, dplyr, and ggplot2 and stores the penguins data as df:

library(palmerpenguins)
library(dplyr)
library(ggplot2)

df <- palmerpenguins::penguins

Manipulate and summarize

The pipeline below returns a table with the mean of every numeric column by species and sex:

df %>%
  dplyr::group_by(species, sex) %>%
  dplyr::summarise(
    dplyr::across(
      dplyr::where(is.numeric), 
      \(x) mean(x, na.rm = TRUE)
      )
    ) %>%
  knitr::kable()

Visualize

The scatter plot below shows bill length against body mass, with a linear fit line for each species:

df %>%
  ggplot2::ggplot(
    ggplot2::aes(
      x = bill_length_mm, 
      y = body_mass_g, 
      color = species)) +
  ggplot2::geom_point() + 
  ggplot2::geom_smooth(method = "lm")

Recap

  1. The eda-basic.qmd file loads palmerpenguins::penguins, groups the data by species and sex, and uses dplyr::across() with where(is.numeric) to compute the mean of every numeric column.

  2. The scatter plot of bill_length_mm against body_mass_g adds a geom_smooth(method = "lm") line for each species. That linear relationship is what the model in Modeling in Python estimates: body mass increases with bill length, and species shifts the baseline.
